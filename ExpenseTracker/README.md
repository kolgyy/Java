# ExpenseTracker

## Описание проекта

**ExpenseTracker** — это настольное графическое приложение для учета финансовых расходов отделов компании.  
Система предназначена для автоматизации процесса внесения информации о закупках, контроля бюджета по категориям товаров и управления финансовыми данными через удобный пользовательский интерфейс.

Приложение разработано на языке **Java** с использованием **JavaFX** и реляционной базы данных **MySQL**.  
Проект реализован с соблюдением принципов объектно-ориентированного программирования, архитектурных паттернов и правил чистого кода.

---

## Назначение системы

Система позволяет:

- Добавлять информацию о закупках отделов компании
- Вести учет расходов по категориям товаров
- Контролировать бюджет, выделенный для каждой категории
- Проверять остаток средств
- Редактировать существующие записи
- Удалять данные из базы
- Работать с данными через графический интерфейс

---

## Основной функционал

### Управление закупками
- Добавление новой записи о закупке
- Указание отдела
- Выбор категории товара
- Внесение суммы расхода
- Сохранение данных в базе

### Контроль бюджета
- Хранение бюджета по категориям
- Проверка превышения лимита
- Отображение актуального остатка средств

### Работа с данными
- Просмотр данных в табличном виде
- Обновление записей
- Удаление записей
- Синхронизация интерфейса с базой данных

---

## Архитектура проекта

Проект реализован с использованием архитектурного подхода MVC (Model-View-Controller):

- **Model** — классы, представляющие бизнес-сущности
- **View** — FXML-файлы интерфейса
- **Controller** — обработка пользовательских действий и логика взаимодействия

### Применяемые принципы

- SOLID-принципы
- Разделение ответственности (Separation of Concerns)
- Инкапсуляция
- Обработка исключений
- Чистая структура проекта

## Работа с базой данных

Приложение использует СУБД MySQL.

Основные сущности базы данных:

- Отделы
- Категории товаров
- Закупки
- Бюджеты

Подключение к базе данных осуществляется через JDBC.
